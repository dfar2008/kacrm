# 使用指南配图来源

配图来源于项目 `hermes-cloud/docs/brand/cloud-market/screens/`。主要维护指南为 `docs/user-guide.md` 与 `docs/user-guide.en.md`，`docs/user-guide.html` 为打印版快照。

指南文字中的产品名称统一为 Kacrm。登录、设置向导、对话演示、新用户模板与聊天截图通过图片编辑工具修正了旧品牌名称；这些图为历史界面的品牌修订示例，不是当前运行版本的实拍截图。其他截图保留来源内容。英文指南还使用 `assets/readme/en/` 中的英文示例图。

英文指南的全部 18 张配图存放于 `assets/user-guide/en/`，中文指南仍引用中文图片；两套配图不混用。英文图是基于历史界面制作的本地化示例。
