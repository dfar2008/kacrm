# Project naming

Use `kacrm` for project identifiers, filenames, services, paths and storage keys.
Use `KaCRM` for the product name in the UI and prose, `Kacrm` for PascalCase
identifiers, and `KACRM` for constants. Apply this convention to future changes.

Keep upstream Hermes names, third-party product names and contributor credits
intact. Changes to the local Hermes overlay must also be captured in
`hermes-patches/` so upgrades preserve them.
